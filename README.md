# Photobooth Studio

Photomaton vintage et éditeur photo, en français.

## Charte graphique validée — 20 octobre 2026
- Fond de l'interface : **#FFFFFF** (blanc pur).
- Texte principal : **#1D1C1A** ; gris secondaire : **#A7A19A**.
- Typographies envisagées : Cormorant Garamond (titres), Satoshi (interface), Space Mono (détails).
- Interface intégralement en français : Accueil, Prendre des photos, Modèles, Filtres, Ombres, Télécharger.
- Templates : Analog Booth, Editorial Collage, Red Room, Blue Room, Polka Dot, Red Paper, Taped Memory, Four Frames.
- Aucun texte décoratif imposé sur les templates ; effets d'ombre réalistes et textures papier.

## Stack
React, TypeScript, Vite, CSS, Canvas API, MediaDevices API. Hébergement cible : GitHub Pages, sous `/photobooth/`.

## Statut
Initialisation du projet. Les fonctionnalités caméra, édition et export seront ajoutées progressivement.
