# Conventions Photobooth Studio
- Interface utilisateur intégralement en français.
- Fond global #FFFFFF, texte #1D1C1A ; couleurs vintage réservées aux modèles.
- Aucun texte décoratif sur les templates exportés.
- Préserver les ombres et les textures lors de l'export.
- React + TypeScript strict, composants réutilisables, accessibilité et mobile-first.
- Ne pas transmettre de photos à un serveur ; traiter localement.
- Tester caméra, import, édition, export et affichage mobile avant de déclarer une fonctionnalité terminée.
